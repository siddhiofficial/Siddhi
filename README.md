# Exploratory Data Analysis (EDA) Course Project – Natural Gas Dataset

## Overview

This repository contains the Exploratory Data Analysis (EDA) Course Project implemented using Python in Google Colab. The project focuses on analyzing a Natural Gas dataset to understand data distributions, identify patterns, explore relationships between variables, and extract meaningful insights through statistical analysis and visualization techniques.

The project also explores dimensionality reduction using Principal Component Analysis (PCA) and predictive modelling using Simple Linear Regression.

## Dataset Description

The project uses the `NaturalGas.csv` dataset, consisting of **138 observations and 11 attributes**.

The dataset contains information related to:
- State and year
- Natural gas consumption
- Natural gas prices
- Electricity and oil prices
- Heating-related variables
- Income

## Project Objectives

The following tasks have been performed as part of the project:

- Loading and understanding the dataset
- Examining dataset structure, dimensions, and data types
- Performing descriptive statistical analysis
- Identifying and handling missing values
- Data cleaning and preprocessing
- Data transformation
- Univariate analysis using multiple visualizations
- Bivariate analysis to explore relationships between variables
- Multivariate analysis to identify patterns and correlations
- Applying Principal Component Analysis (PCA) for dimensionality reduction
- Implementing Simple Linear Regression (SLR) to analyze the relationship between natural gas price and consumption
- Visualizing and interpreting analytical results
