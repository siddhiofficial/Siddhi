# Exploratory Data Analysis (EDA) Course Project – Phase 1

## Overview

This repository contains the Phase 1 submission for the Exploratory Data Analysis (EDA) Course Project. The objective of this phase is to perform data preprocessing, statistical analysis, and exploratory data analysis using Python in Google Colab.

## Project Objectives

The following tasks have been completed as part of Phase 1:

- Loading the dataset
- Performing basic statistical analysis
- Handling missing values
- Data cleaning
- Data transformation
- Univariate analysis (minimum three visualizations)
- Bivariate analysis (minimum three visualizations)
- Multivariate analysis (minimum three visualizations)

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Repository Structure

```
├── README.md
└── EDA_Phase1.ipynb
```

## How to Run

1. Clone or download this repository.
2. Open `EDA_Phase1.ipynb` using Google Colab or Jupyter Notebook.
3. Upload the required dataset when prompted.
4. Run all cells sequentially to reproduce the analysis and visualizations.

## Results

The notebook demonstrates:
- Data preprocessing and cleaning
- Descriptive statistical analysis
- Data transformation techniques
- Exploratory visualizations to identify trends, distributions, and relationships among variables
